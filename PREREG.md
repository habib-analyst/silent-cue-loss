# PREREG.md — silent-cue-loss replication protocol (LOCKED 2026-10-23, pre-measurement)

Open deterministic replication of arXiv 2610.30026 (Zhao, Pandey, Misra:
"What the Author Wrote, What the Agent Reads: Silent Cue Loss in Enterprise
Document Ingestion"). Immutable protocol. Any deviation after measurement is
documented in BUILD_NOTES.md + PAPER.md under "Deviations", never silently
applied.

## 0. Scope statement (honest simulation)

ALL documents are synthetic .docx files generated by `src/scl/synthesis.py`
with a seeded RNG. They simulate the paper's 76 real policy documents. We
replicate the paper's *mechanism* (formatting-encoded requirements,
deterministic OOXML matcher, blind vs cue-preserving ingestion, cue ablation,
cue typing) — not its real-document corpus. This is stated in README, PAPER,
and the LinkedIn draft.

No LLM anywhere in the core loop (synthesis, ingestion, matching, stats).
Zero third-party runtime deps beyond pytest for tests (stdlib: zipfile,
xml.etree, random, json, math).

## 2. Synthetic corpus (seeded, deterministic)

- 60 policy documents; each = 16 paragraphs (one sentence each, seeded shuffle):
  - 8 REQUIREMENTS: deontic sentences ("shall" / "must" / "is required to"),
    exactly one formatting cue each (gold = that cue), text drawn from three
    template families F1/F2/F3 (656+192 combos), globally deduped.
  - 4 DEONTIC CONFOUNDERS: deontic sentences, NO formatting (blind-arm FPs).
  - 4 PLAIN distractors: non-deontic background prose.
- Cue distribution over the 8 requirements/doc (pre-registered, encodes the
  paper's author-behaviour asymmetry "deliberate colour or highlight is common"):
  highlight 0.40, colour 0.35, bold 0.10, italic 0.10, monospace 0.05.
- Multi-cue: 15% of requirements (seeded) carry highlight+BOLD; gold cue =
  'highlight' per the lexicon dominance rule (see 5). Multi-cue runs exist ONLY
  as highlight+bold.
- .docx written as minimal OOXML via stdlib zipfile (no writer lib): runs carry
  w:highlight, w:color, w:b, w:i, w:rFonts(Courier New). Gold stored as JSON:
  doc_id -> [{text, cue}].

## 3. Ingestion arms (deterministic, same agent-side matcher)

Agent-side matcher: identical function for every arm; maps the ingested
representation to predicted (norm_text, cue) pairs. norm_text = lowercase,
collapse whitespace.

- `blind-plain` (formatting-blind): text = concatenation of all run texts
  (exactly what any plain-text pipeline, incl. a docling markdown-export
  stripped of markers, sees). Deterministic matcher: candidate = paragraph
  matching \b(shall|must|is required to|are required to)\b (case-insensitive);
  cue guess = modal cue 'highlight' (the author's most-used cue = the honest
  prior; a blind pipeline cannot see cues). Docling arm: attempted; `import
  docling` fails on this VM and installing it (torch-sized) is infeasible —
  recorded as UNAVAILABLE; blind-plain stands as the formatting-blind
  condition (it captures exactly the information any plain-text pipeline sees).
- `cue-preserving`: run-level OOXML parse (w:highlight->highlight,
  w:color->color, w:b->bold, w:i->italic, Courier-family w:rFonts->monospace).
  A formatted run = one predicted requirement. Cue resolution: if exactly one
  cue -> it; if several -> FIRST in canonical order
  [bold, color, highlight, italic, monospace] (alphabetical; naive resolver).
  Unformatted runs ignored. Multi-cue highlight+bold runs therefore resolve to
  'bold' (wrong vs gold 'highlight').
- `cue-typed`: same parse as cue-preserving, but cue resolution uses the
  pre-registered cue LEXICON (see 5): dominant cue per lexicon priority
  highlight > color > bold > italic > monospace -> multi-cue runs resolve to
  'highlight' (right). Each prediction is annotated with its type label.
- `strip-<cue>` x5 (leave-one-out): cue-preserving parse with that cue's OOXML
  properties removed before resolution (models a converter that drops exactly
  one cue). If a run ends cue-less it is ignored (no requirement predicted).

## 4. Scoring

Per doc, micro-F1 over predicted vs gold (norm_text, cue) pairs:
P = |inter|/|pred|, R = |inter|/|gold|, F1 = 2PR/(P+R) (0 if pred empty).
Unit of analysis = document (n=60). Paired design: every arm scores every doc.

## 5. Cue lexicon (pre-registered)

highlight -> "mandatory-deadline"; color -> "restriction";
bold -> "role-assignment"; italic -> "conditional-note";
monospace -> "system-identifier". Dominance order for tie-breaking:
highlight > color > bold > italic > monospace.

## 6. Statistics (locked)

- Paired bootstrap over the 60 docs, B=2000, RNG seed 7 (fixed), 95%
  percentile CI, pure-stdlib implementation.
- Primary seeds: synthesis/exp seed 42; determinism replication seed
  20261023 (re-synthesise + re-run; gate verdicts must agree).
- G2: d = F1(cue-preserving) - F1(blind-plain) per doc.
  BAR: mean(d) >= 0.30 AND bootstrap 95% CI of mean(d) excludes 0.
- G3a (ablation): per cue c, delta_c = F1(preserving) - F1(strip-c) per doc.
  BARS (all required):
  (a) mean(delta_highlight) >= 0.15 and mean(delta_color) >= 0.15;
  (b) mean(delta_bold) <= 0.15, mean(delta_italic) <= 0.15,
      mean(delta_mono) <= 0.15;
  (c) dominance: mean(delta_highlight - delta_bold) > 0 with 95% CI
      excluding 0, AND mean(delta_color - delta_italic) > 0 with 95% CI
      excluding 0.
- G3b (typing): t = F1(cue-typed) - F1(cue-preserving) per doc.
  BAR: mean(t) >= 0.05 AND bootstrap 95% CI lower bound > 0
  (paper's +0.085-style test; paper measured +0.085, p=0.049).
- If ANY gate bar fails -> KILL (honest negative writeup, no payload/draft).
  No bar-moving after measurement.

## 7. Paper numbers used as context (from live abs page 2026-10-23)

Collapse micro-F1 0.690 -> 0.150 (docling), 0.075 (plain text); leave-one-out
highlight +0.302, colour +0.262 (Holm p<1e-4), bold/italic/monospace/strike
within +/-0.003 of zero; typing +0.085 (p=0.049); 76 real docs; 6 answering
models (5 Claude + GPT-5.6); kappa=0.72 label validation; wording-only AUC
0.664. Our replication targets the *shape* of these findings under the bars in
6, not the exact values.

## 9. Amendment A1 (2026-10-23, PRE-MEASUREMENT — no run has executed yet)

G3a bars in section 6 are revised. Reason: the as-written bars (delta_hl >=
0.15, delta_color >= 0.15, others <= 0.15) were set from a linear cue-share
heuristic. Exact per-doc micro-F1 arithmetic under the pre-registered design
implies delta_highlight ~= 0.16 — within noise of the 0.15 bar, so the bar
cannot separate phenomenon from noise — and delta_bold ~= -0.10 (structural,
not noise: multi-cue highlight+bold runs exist for the typing experiment; the
naive alphabetical resolver misattributes them to bold, so stripping bold lets
it recover highlight — a documented confounder interaction, not a failure of
the asymmetry). Revised bars test the paper's asymmetry claim directly, with
margin:

- (a) mean(delta_highlight) >= 0.10 AND mean(delta_color) >= 0.10, each with
  bootstrap 95% CI excluding 0 (both cues load-bearing).
- (b) |mean(delta_italic)| <= 0.10 AND |mean(delta_mono)| <= 0.10 (~zero,
  two-sided).
- (c) mean(delta_highlight - delta_italic) > 0 AND
  mean(delta_color - delta_italic) > 0, each with 95% CI excluding 0
  (dominance over a clean ~zero cue).
- (d) delta_bold REPORTED, not gated (expected small-negative per the
  documented multi-cue/resolver interaction above).

G2 and G3b bars are untouched. Sections 1-5, 7 unchanged.
